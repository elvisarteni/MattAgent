VERO STATUS 4.3  (ASPF-1578)
============================

Shows in your browser whether Vero is available and which model it uses.
Needs Python 3.8+ only. Nothing to install. No command window.

1. Put this folder somewhere fixed, e.g.  C:\Tools\vero-status

2. Double-click  "Vero Status.pyw"
   Your browser opens the dashboard (http://127.0.0.1:8767). The first check takes about a minute.

3. Optional: right-click "Vero Status.pyw" -> Send to -> Desktop (create shortcut).
   To start it with Windows: Win+R -> shell:startup -> put that shortcut there.

In the dashboard:  Check now  |  Settings (how often, which model, Vero location)  |  Quit

If an older version is installed (Vero Latency Monitor or Vero Availability Monitor), run
uninstall.bat in its folder so it stops calling Vero.

TEAM SERVER (one shared page, no login): on an always-on machine run
   python vero_status_server.py
and share the link it prints. See README.md, section Team server.

LINUX VM (no desktop):  bash scripts/install_vm.sh   (see README.md, On a Linux VM)

Problems: open data\vero-status.log, or read Vero_Status_Guide.pdf.
